# 운전대를 놓은 노인은 어디로 가는가

나이 든 운전자가 운전면허를 스스로 반납하면, 그 뒤에 무엇을 타고 이동할지가 문제가 됩니다.
버스가 거의 다니지 않는 지역이라면 병원이나 시장에 가는 일부터 어려워집니다.
이 저장소는 **공공데이터로 그런 지역이 어디인지 찾고, 어떤 지원이 필요한지 제안한** 분석의 코드와 자료를 담고 있습니다.

- 공모전: 「AI와 함께하는 교통문제 해결을 위한 데이터 분석 공모전」
- 팀: 안전 면허 (김민규)
- 분석보고서: [`report/안전 면허_분석보고서.pdf`](report/안전%20면허_분석보고서.pdf)

---

## 분석 질문

1. 버스 이용이 적은 지역은 면허 반납도 적은가?
2. **노인이 많고, 버스가 거의 다니지 않고, 교통사고 사망이 많은 지역**은 어디이며 몇 곳인가?
3. 면허를 반납한 노인이 계속 이동하려면 어떤 지원이 필요한가?

---

## 핵심 결과

### 1. 교통사고 사망자의 절반 이상이 65세 이상입니다

2025년 교통사고 사망자 2,549명 중 1,378명(54.1%)이 65세 이상이었습니다.
65세 이상은 전체 인구의 20.6%에 불과합니다. 인구 규모를 고려하면 65세 이상의 사망률은 65세 미만의 **4.5배**입니다.

### 2. 65세 이상 운전자가 낸 사고의 비중이 10년 사이 두 배 가까이 늘었습니다

교통사고 사망자 가운데 65세 이상 운전자가 낸 사고로 숨진 사람의 비중은 17.6%(2015년)에서 33.1%(2025년)로 늘었습니다.

### 3. 면허 반납은 81배 늘었지만, 지역 간 차이가 2배 가까이 됩니다

- 65세 이상 면허 반납: 1,415건(2015년) → 114,436건(2024년)
- 65세 이상 1,000명당 반납(2024년): 부산 14.4건(최고), 전남 7.3건(최저)
- 시도별로 보면 **버스를 많이 타는 지역일수록 반납도 많았습니다.** (스피어만 순위상관 ρ = 0.70. 두 순위가 같은 방향으로 움직이는 정도이며, 1에 가까울수록 관계가 강합니다.)

### 4. 버스 이용이 가장 적은 지역의 교통사고 사망률은 5.8배 높습니다

전국 시군구를 1인당 버스 승차 횟수 순으로 세운 뒤 다섯 묶음(각 20%)으로 나누었습니다.
버스를 가장 적게 타는 20%에서는 인구 10만 명당 15.9명이 교통사고로 숨졌고, 가장 많이 타는 20%에서는 2.7명이었습니다.

### 5. 65세 이상 운전자의 사고 건수는 비슷하지만, 사망자는 5.7배입니다

| 버스 이용 | 65세 이상 1,000명당 사고 | 65세 이상 10만 명당 사망 |
| --- | --- | --- |
| 가장 적은 20% | 4.21건 | 21.15명 |
| 가장 많은 20% | 4.17건 | 3.73명 |

### 6. '이동 사각지대' 46곳을 찾았습니다

이동 사각지대는 아래 세 조건에 모두 해당하는 시군구입니다.

- 65세 이상 인구 비율이 높다 (상위 1/3)
- 1인당 버스 이용이 적다 (하위 1/3)
- 교통사고 사망률이 높다 (상위 1/3)

이 46곳에는 전국 인구의 **4.1%**가 살지만, 전국 교통사고 사망자의 **16.5%**가 이곳에서 발생했습니다.
46곳 중 41곳이 군 지역이며, 경북(12곳)·전남(10곳)·경남(8곳)·충남(6곳)에 많습니다.

### 7. 반납률 1위 부산: 도시철도가 노인의 이동을 받치지만, 빈틈도 있습니다

- 부산 도시철도 승차 중 무임(경로 등) 승차 비중: 25.8%(2014년) → 34.1%(2024년)
- 부산의 고령운전자 사고 사망자는 65세 이상 10만 명당 3.15명으로, 전국(7.62명)의 절반에 못 미치며 17개 시도 중 가장 적습니다.
- 도시철도가 닿지 않는 곳은 사정이 다릅니다. 교통약자 특별교통수단 '두리발'은 2025년 5월 한 달 동안 37,194건 호출되었고, 그중 **9.4%는 차량을 배정받지 못했습니다.** 대기 시간의 중간값은 42분이었습니다.
- 보행노인 교통사고 다발지역 지정 기록(2023~2025년) 781건 중 129건이 부산입니다. 부산의 65세 이상 인구는 전국의 7.6%입니다.

## 정책 제안

1. **면허 반납과 이동 보장을 함께 제공:** 일회성 교통카드 대신, 수요응답형 교통(DRT, 호출하면 오는 버스)이나 공공형 택시 이용권을 지원합니다.
2. **'이동 사각지대 지수'로 예산 배분:** 이번 분석의 지표로 매년 지역 순위를 다시 매겨, 대중교통 지원의 우선순위를 정합니다.
3. **반납 이후의 보행 안전:** 반납한 노인은 보행자가 되므로, 정류장·경로당 주변을 노인보호구역으로 우선 지정합니다.

자세한 내용과 기대효과는 [분석보고서](report/안전%20면허_분석보고서.pdf)에 있습니다.

## 재현 방법

Python 3.13 환경에서 작성했습니다. 아래 순서대로 실행하면 보고서와 **같은 수치**가 나옵니다(예: 이동 사각지대 46곳).

**1) 패키지 설치**

```bash
pip install -r requirements.txt
```

**2) 원본 자료를 시군구별 표로 정리** → `data/processed/`

```bash
python analysis/01_build_panel.py
```

**3) 분석 및 그림 1~4 생성** → `outputs/`

```bash
python analysis/02_analysis.py
```

**4) 비교용: 초기 방식(2026년 9월 인구)으로 재계산** → `outputs_file2026/`

```bash
POP_SOURCE=file2026 python analysis/01_build_panel.py
POP_SOURCE=file2026 python analysis/02_analysis.py
```

Windows PowerShell에서는 `$env:POP_SOURCE="file2026"`을 먼저 입력한 뒤 위 두 명령을 실행하고, 끝나면 `Remove-Item Env:POP_SOURCE`로 설정을 지웁니다.

**5) 수치 검증: 초기 방식과 API 자료 기반 결과를 비교** → `outputs/verification.json`

```bash
python analysis/03_verify.py
```

**6) 부산 사례 분석 및 그림 5 생성** → `outputs/results_busan.json`

```bash
python analysis/04_busan_case.py
```

**7) 공모전 양식 분석보고서 PDF 생성** → `report/안전 면허_분석보고서.pdf`

```bash
python -m playwright install chromium
python report/build_report_form.py
```

보고서의 수치는 사람이 옮겨 적지 않으며, 코드가 `outputs/results.json`에서 읽어 자동으로 채웁니다.

## AI 활용

- **자료 탐색·수집:** 직접 개발한 자료 수집 도구 **rdhub**를 AI(Claude)가 호출해 사용했습니다. 자료 검색 → 원문 페이지에서 제공기관·이용 조건 확인 → 파일 내려받기 → 파일 지문 기록 → 표 정리 순서로 진행했으며, 모든 호출 기록은 `logs/`에 있습니다.
- **코드·보고서 초안:** Claude와 함께 작성했습니다.
- **수치 입력 방식:** AI가 기억에 의존해 수치를 적지 않도록, 보고서의 모든 수치는 분석 결과 파일에서 자동으로 가져옵니다.
- **재계산 검증:** 처음에는 2026년 9월 인구로 계산했습니다. 이후 사고·반납이 발생한 해의 6월 인구를 KOSIS OpenAPI로 받아 전부 다시 계산했으며, 결론은 달라지지 않았습니다. 비교표는 `outputs/tables/table_verification.csv`에 있습니다.

## 한계

- **인과관계를 증명한 분석이 아닙니다.** 시군구 단위에서 함께 나타나는 경향을 확인한 것입니다.
- **자료의 기준 연도가 일부 다릅니다.** 사고·반납과 인구는 같은 해로 맞췄지만, 자동차 주행거리는 2019년 자료입니다.
- **'고령운전자 사고 사망자'에는 해당 사고의 모든 사망자가 포함됩니다.** 운전자 본인뿐 아니라 상대 차량 탑승자와 보행자도 포함됩니다.
- **버스 이용은 교통카드 기록만 반영했습니다.** 현금 승차와 수요응답형 교통(DRT)은 빠져 있습니다.
- **부산 자료에는 공백이 있습니다.** 두리발 자료는 교통약자 대상 한 달치 기록이며, 노인보호구역 자료는 16개 구군 중 11곳만 제공됩니다.
- **이산화탄소 감축량은 가정을 바탕으로 한 추정치입니다.** 계산 방법은 보고서에 있습니다.
